# YouTube Downloader

Расширение Chrome с кнопкой «Скачать» на странице ролика и Shorts. Само видео забирает локальный [yt-dlp](https://github.com/yt-dlp/yt-dlp), а дорожки склеивает ffmpeg. Плейлисты не скачиваются: только открытый ролик.

Папка по умолчанию: `~/Downloads/YouTube`. Её можно сменить во всплывающем окне расширения. Нужен полный путь внутри домашнего каталога, например `/home/user/Downloads/YouTube`.

## Установка

1. Поставьте программы. Пакет `yt-dlp` из репозитория Ubuntu часто слишком старый и не видит форматы YouTube, поэтому нужен актуальный бинарник:

```bash
sudo apt install ffmpeg
mkdir -p ~/.local/bin
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp
chmod +x ~/.local/bin/yt-dlp
```

Хост сам смотрит `~/.local/bin`, даже если этот каталог не попал в PATH браузера.

2. Откройте `chrome://extensions`, включите режим разработчика и загрузите распакованную папку `extension`.
3. Из корня этого проекта выполните:

```bash
./native-host/install.sh
```

4. На `chrome://extensions` нажмите «Обновить» у карточки YouTube Downloader и обновите вкладку с роликом.

Скрипт регистрирует хост `com.alena.ytdlp` в `~/.config/google-chrome`. Если уже есть каталоги `~/.config/chromium` или `~/.config/microsoft-edge`, хост ставится и туда. Для Chromium GOST используется `~/.config/chromium-gost`. Если проект переехал на диске, запустите `install.sh` ещё раз: в манифесте хоста записан полный путь к `native-host/ytdlp_host.py`.

## Как пользоваться

На странице ролика или Shorts нажмите «Скачать», выберите качество или «Только аудио» и дождитесь пути к файлу. «Отмена» останавливает yt-dlp. Пока одно скачивание не закончилось, второе не запустится.

Если хост не подключён или нет yt-dlp/ffmpeg, панель покажет текст ошибки и команду установки.

## Ограничения

- Ролики с проверкой «вы не бот» или возрастным ограничением могут не скачаться: cookies браузера расширению не передаются.
- Установщик рассчитан на Linux. Само расширение от системы не зависит, но без локального хоста кнопка не скачает файл.
